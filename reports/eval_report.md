# Évaluation NL-to-SQL

Aucun résultat d'évaluation à jour n'est disponible pour le Czech Financial Dataset.
Le rapport précédent (19/20) portait sur l'ancien jeu de données tunisien et ne mesure
pas le comportement du moteur actuel.

Après avoir chargé les données et configuré `GROQ_API_KEY`, exécuter
`python -m engine.evaluate` depuis la racine du projet pour générer un rapport valide.
Cette commande effectue des appels à l'API Groq.
